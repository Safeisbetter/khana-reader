**Experimental Windows build. It has not been tried on a real PC.** An automatic check on GitHub's Windows computers reads a text, makes the voice speak, saves a WAV, reads a picture (and, in the full edition, translates a text); nobody has opened the window yet.

Two files: download one, unzip it, and double-click `KhanaReader.exe` (see `README-Windows.txt` inside).
- `KhanaReader-Windows-light-experimental.zip` (about 0.5 GB): the **light** edition, without translation.
- `KhanaReader-Windows-full-experimental.zip` (about 1.1 GB): the **full** edition, which also translates foreign books into Farsi (the smaller 600M translation model, the same as on Android).

Not in these versions: MP3 (WAV instead), the translated PDF, Word/RTF/ODT files.

If something goes wrong, please open an issue. Please do not attach books you would not like to make public.
