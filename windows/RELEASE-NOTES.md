**Experimental Windows build. It has not been tried on a real PC.** An automatic check on GitHub's Windows computers reads a text, makes the voice speak, saves a WAV and reads a picture; nobody has opened the window yet.

Download `KhanaReader-Windows-experimental.zip` (about 0.65 GB), unzip it, and double-click `KhanaReader.exe` (see `README-Windows.txt` inside).

Not in this version: translation, MP3 (WAV instead), the translated PDF, Word/RTF/ODT files.

If something goes wrong, please open an issue. Please do not attach books you would not like to make public.
